## Description

*(Paste the full work item description. Prefilled when fetched from a tracker.)*

```
A citizen should not be able to submit the same request twice while the first one is still being handled.

- If the citizen already has an open request (SUBMITTED or UNDER_REVIEW) for the same service, a new submit for that service fails with a clear error that includes the existing reference number.
- A different service is fine.
- After the open request gets a decision, the citizen can submit again.
```
