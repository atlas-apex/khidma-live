# KH-107 · Withdraw a request

Citizens can withdraw a request while it is still SUBMITTED, before staff start the review.

- Only the citizen who submitted the request can withdraw it (pass citizenId; a different citizen gets an error).
- A request can be withdrawn only while its status is SUBMITTED. If it is UNDER_REVIEW, APPROVED or REJECTED, withdrawing fails with a clear error.
- Withdrawing moves the request to a new final status, WITHDRAWN, and adds it to the request history.
- A WITHDRAWN request cannot be reviewed or decided.
- A WITHDRAWN request is not "open": the citizen can submit a new request for the same service.

Technical hint: add `withdrawRequest(id, citizenId)` to `src/requests.js`.

Acceptance: one test per rule. All existing tests still pass. No new dependencies.
